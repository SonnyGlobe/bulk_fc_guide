🧭 QGIS Nearest Facility Guide

Complete Workflow: From Lat/Lon CSV to Real Meter Distances

1Load Raw CSV Data

Import your initial.csvcoordinates into QGIS.

  • Layer→Add Layer→Add Delimited Text Layer
  • Select your Facility and POI CSVs.
  • X field:Longitude |Y field:Latitude
  • Geometry CRS:DefaultEPSG:4326 - WGS 84.
The "Decimal" TrapAt this stage, QGIS measures distance inDegrees. This is why you see0.00016instead of meters.

2Reproject (The Meters Fix)

YouMUSTconvert the coordinate system to a projected one (UTM) to use meters.

Step-by-Step Reprojection:
  1. Right-click the layer in the Layers Panel.
  2. ChooseExport→Save Features As...
  3. Format:Change toGeoPackage(Do not use CSV!).
  4. CRS:SelectEPSG:32651 - WGS 84 / UTM zone 51N.
  5. Save asPOI_Meters.gpkg.
  6. Repeatfor the Facility layer.

Note: GeoPackage preserves the meter projection; CSV does not.

3Join Attributes by Nearest

Now that both layers are inGeoPackage (UTM Zone 51N), run the analysis.

  • OpenProcessing Toolbox→Join attributes by nearest
  • Input Layer:POI_Meters
  • Input Layer 2:Facility_Meters
  • Maximum distance:250(QGIS now knows this is 250 METERS)
  • Discard records:Optional (Check this to only show matches within 250m).

Troubleshooting & Logic

ISSUEDistance column shows0.000...

FIXYou are still using the CSV layers. Remove them from the map and only use theGeoPackagefiles.

ISSUENo results (NULL values)

FIXNo facility is within 250m. Try a test run with1000to confirm the tool is working.

UTM (Universal Transverse Mercator)is a meter-based grid system used in GIS so distances become accurate and measurable.
