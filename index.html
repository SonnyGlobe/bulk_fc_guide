🧭 QGIS Bulk Facility Checking

Complete workflow guide for converting Latitude & Longitude CSV files into accurate meter-based nearest facility analysis using QGIS.

▶ Video Tutorial — Bulk Facility Checking

1Load Raw CSV Data

Import your coordinate CSV files into QGIS.

  • Open:Layer → Add Layer → Add Delimited Text Layer
  • Select your:Facility CSVandPOI CSV
  • X Field:Longitude
  • Y Field:Latitude
  • CRS:EPSG:4326 - WGS 84
Important:
CSV layers use geographic coordinates (degrees), not meters. That is why distances appear like0.00016.

2Reproject to UTM (Meters Fix)

Convert both layers into a projected CRS so QGIS can calculate real meter distances.

Step-by-Step Reprojection
  1. Right-click the layer
  2. Choose:Export → Save Features As...
  3. Format:GeoPackage
  4. CRS:EPSG:32651 - WGS 84 / UTM Zone 51N
  5. Save as:POI_Meters.gpkg
  6. Repeat for Facility layer
Why GeoPackage?
GeoPackage preserves projected coordinates and meter values. CSV does not properly preserve GIS projections.

3Run Nearest Facility Analysis

Now both layers are in UTM meters and ready for analysis.

  • Open:Processing Toolbox
  • Search:Join attributes by nearest
  • Input Layer:POI_Meters
  • Input Layer 2:Facility_Meters
  • Maximum Distance:250(250 METERS)
  • Optional:Discard records which could not be joined

4Verify Coordinates

Make sure the layer is really projected into meters.

  • Open:Attribute Table
  • Use:Field Calculator
  • Create fields:$xand$y

✅ Correct Values:300000+,1100000+

❌ Wrong Values:121.xxx,14.xxx

⚠ Troubleshooting

ISSUE

Distance column shows:0.000...

FIX

You are still using the original CSV layers. Remove them and only use the.gpkgprojected layers.

ISSUE

Result fields are NULL

FIX

No facility exists within 250 meters. Test using:1000meters.

What is UTM?
UTM (Universal Transverse Mercator) is a projected coordinate system that converts Earth coordinates into accurate meter measurements.
